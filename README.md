# Fieldnotes · 工程伦理案例分析工作台

离线、中英文、按教材十步方法辅助人工分析。可创建不同案例，自己添加事实与来源，记录问题、依据和判断；程序**不生成结论**。

## 运行方式

**双击 `index.html` 即可运行，零依赖、零联网。**  
开发阶段用根目录 `index.html`；最终交付物为 `dist/index.html`（由 `tools/build.py` 内联打包）。

## 目录地图

| 路径 | 说明 |
|------|------|
| `index.html` | 开发入口页面 |
| `src/data/` | 案例静态数据与用户 mock 状态 |
| `src/logic/` | 已合入的状态与校验骨架，导入导出待实现 |
| `src/ui/` | 界面组件与交互（组员） |
| `src/styles/` | 样式（组员） |
| `docs/` | 产品规格、数据契约、决策与 AI 日志 |
| `tools/` | 单文件构建、数据与交付检查脚本 |
| `dist/` | 最终交付的单文件 HTML |

## 当前状态

所有前端内容与最新逻辑层、研究草稿已整合到 `main`。工作台使用深蓝导航、蓝灰画布和按阶段变化的蓝、紫、青绿及暖棕强调色；桌面导航字号为 16px。十步填写区、资料抽屉与弹窗使用统一卡片和表单样式，低频功能按需打开。

右上角「案例」可新建和切换案例。每个案例独立保存，自建案例的事实、来源和分析可打包为 JSON，在另一台电脑载入；Markdown 用于整理人工撰写的素材。工作台标题与导航不绑定具体案例名称。

「资料与依据」用于查看材料、核对出处，并手动关联问题和填写理由。第 3 步只显示自己选用的事实；一条事实可有多个类别，页面只展示一次。预置资料包 2.1 已加入 50 条事实、15 条时间线及出处/原文/核验备注，界面保留“待复核”提示；资料包的置信度不等于程序核验。

单文件：双击 `preview.html`；更新：`python src/ui/build-preview.py`。源码入口仍为 `index.html`。`src/logic/` 的导入导出尚未完成，当前界面继续使用 `src/ui/preview-runtime.js`，保留替换接口。新建案例从空白材料开始，不继承预置案例的报告评估与解释性参考。

正式构建：`python tools/build.py` → `dist/index.html`；检查：`python tools/check-dist.py`。该文件也已包含最新页面样式。仓库新增 AppLogicRuntime 适配器，目前工作台仍选用已验证的预览运行时，切换接入单独进行。

运行时接口、验证方式与交付边界见 [前端交接说明](docs/FRONTEND.md)。
