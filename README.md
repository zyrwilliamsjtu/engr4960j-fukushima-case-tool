# 福岛案例分析引导工具（ENGR4960J）

离线单文件网页：按教材 10 步分析法，引导用户逐步填写福岛第一核电站事故案例分析，**不生成结论**。

## 运行方式

**双击 `index.html` 即可运行，零依赖、零联网。**  
开发阶段用根目录 `index.html`；最终交付物为 `dist/index.html`（由 `tools/build.py` 内联打包）。

## 目录地图

| 路径 | 说明 |
|------|------|
| `index.html` | 开发入口页面 |
| `src/data/` | 案例静态数据与用户 mock 状态 |
| `src/logic/` | 步骤流转、校验、存储、导出（待实现） |
| `src/ui/` | 界面组件与交互（组员） |
| `src/styles/` | 样式（组员） |
| `docs/` | 产品规格、数据契约、决策与 AI 日志 |
| `tools/` | 单文件构建脚本（待实现） |
| `dist/` | 最终交付的单文件 HTML |
