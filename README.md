# Fieldnotes · 工程伦理案例分析工作台

离线、中英文、按教材十步方法辅助人工分析。可创建不同案例，自己添加事实与来源，记录问题、依据和判断；程序**不生成结论**。

## 运行方式

**双击 `index.html` 即可运行，零依赖、零联网。**  
开发阶段用根目录 `index.html`；最终交付物为 `dist/index.html`（由 `tools/build.py` 内联打包）。

## 目录地图

| 路径 | 说明 |
|------|------|
| `index.html` | 开发入口页面 |
| `src/data/` | 案例静态数据与用户 mock 状态 |
| `src/logic/` | 已合入的状态与校验骨架，导入导出待实现 |
| `src/ui/` | 界面组件与交互（组员） |
| `src/styles/` | 样式（组员） |
| `docs/` | 产品规格、数据契约、决策与 AI 日志 |
| `tools/` | 单文件构建、数据与交付检查脚本 |
| `dist/` | 最终交付的单文件 HTML |

## 当前状态

所有前端内容与最新逻辑层、研究草稿已整合到 `main`。工作台使用深蓝导航、蓝灰画布和按阶段变化的蓝、紫、青绿及暖棕强调色；桌面导航字号为 16px。十步填写区、资料阅读区与弹窗使用统一卡片和表单样式，低频功能按需打开。

右上角「案例」可新建和切换案例。每个案例独立保存，自建案例的事实、来源和分析可打包为 JSON，在另一台电脑载入；Markdown 用于整理人工撰写的素材。工作台标题与导航不绑定具体案例名称。

「资料与依据」采用可搜索的列表与阅读区，支持类别、来源和已引用筛选；核对原文后，在同一页关联问题并填写理由，保存后可继续浏览。来源目录可反查相关资料，原则库可连续选择多项，第 4 步的假设依据也支持搜索。第 3 步只显示自己选用的事实；一条事实可有多个类别，页面只展示一次。预置资料包 2.1 已加入 50 条事实、15 条时间线及出处/原文/核验备注，界面保留“待复核”提示；资料包的置信度不等于程序核验。

单文件预览：双击 `preview.html`；更新：`python src/ui/build-preview.py`。正式构建：`python tools/build.py` → `dist/index.html`；检查：`python tools/check-dist.py`。正式交付页的内置案例通过 AppLogic 适配器运行；逻辑层暂时只接受内置案例 ID，自建案例继续使用可保存、可导出导入的兼容运行时，避免串入预置案例。

### 交付物 vs 演示版

| 文件 | 用途 |
|------|------|
| `dist/index.html` | **正式交付物**：空白开始，不含任何示例输入或演示提示。 |
| `dist/index.demo.html` | **课堂演示版**：预填 `src/data/demo-state.js` 中的本组示例分析（非标准答案）；构建命令：`python tools/build.py --extra-js src/data/demo-state.js --extra-js tools/demo-boot.js --out dist/index.demo.html`。 |

十步标题旁的「填写提示」首次点击展开，再次点击轮换，也可使用「换个角度」。共 31 条中英文思考提示与表达示例，由小组编写，标明非教材原句；不会替用户填入分析。资料列表每页 12 条，搜索覆盖全部记录；桌面加宽列表，手机使用列表与详情两个独立视图。

运行时接口、验证方式与交付边界见 [前端交接说明](docs/FRONTEND.md)。

产品定位、当前功能、架构图与课堂演示建议见 [PPT 制作参考](docs/PPT_REFERENCE.md)。
