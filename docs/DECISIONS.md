# 架构与产品决策日志

格式：`日期 / 决策 / 理由`（一条一行）

2025-10-11 / 不使用任何 API 与后端 / 交付形态是单个 HTML 文件，无服务器可部署。
2025-10-11 / 不使用 React/Vue、不用 CDN / 必须离线双击运行。
2025-10-11 / 不使用 ES Module 与 fetch 读本地 JSON / file:// 协议下会被 CORS 拦截。
2025-10-11 / 只做福岛一个案例 / 多案例是无底洞，且演示时间只有 12–13 分钟。
2025-10-11 / 程序不生成结论 / 作业要求工具「辅助人工分析」而非替代人工。
2026-10-11 / 去掉硬性闯关，改为草稿 + 集中提醒 / 避免分析被降格为凑数打卡。
2026-10-11 / 原始材料与参考观点分层（L1/L2/L3） / 材料随时可读，只有解释性观点门控。
2026-10-11 / 第 6 步除拖拽外必须提供上下移动按钮 / 投影环境下拖拽不可靠。
2026-10-11 / 第 9 步由「缓解/豁免条件」改为「现实约束与责任判断」 / 原名暗示勾选即免责。
2026-10-11 / 不启用 GitHub 分支保护，改为团队约定 + 群内公告 / 2 人团队，避免 PR 等人卡死。
2026-10-11 / 纯文档可自合并 / 判断标准是「是否改变双击 index.html 后的行为」。
2026-10-11 / 静态数据 ID 统一为 f-mat- / f-ind- / f-org- / tl- 等前缀，引用时直接写原 id / 避免界面层与数据层各自假设一套 id。

2026-10-11 / 双语只翻译 UI，不改用户原文 / 保留作者意思，教材原句另行保留。
