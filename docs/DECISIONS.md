# 架构与产品决策日志

格式：`日期 / 决策 / 理由`（一条一行）

2025-10-11 / 不使用任何 API 与后端 / 交付形态是单个 HTML 文件，无服务器可部署。
2025-10-11 / 不使用 React/Vue、不用 CDN / 必须离线双击运行。
2025-10-11 / 不使用 ES Module 与 fetch 读本地 JSON / file:// 协议下会被 CORS 拦截。
2025-10-11 / 只做福岛一个案例 / 多案例是无底洞，且演示时间只有 12–13 分钟。
2025-10-11 / 程序不生成结论 / 作业要求工具「辅助人工分析」而非替代人工。
2026-10-11 / 去掉硬性闯关，改为草稿 + 集中提醒 / 避免分析被降格为凑数打卡。
2026-10-11 / 原始材料与参考观点分层（L1/L2/L3） / 材料随时可读，只有解释性观点门控。
2026-10-11 / 第 6 步除拖拽外必须提供上下移动按钮 / 投影环境下拖拽不可靠。
2026-10-11 / 第 9 步由「缓解/豁免条件」改为「现实约束与责任判断」 / 原名暗示勾选即免责。
2026-10-11 / 不启用 GitHub 分支保护，改为团队约定 + 群内公告 / 2 人团队，避免 PR 等人卡死。
2026-10-11 / 纯文档可自合并 / 判断标准是「是否改变双击 index.html 后的行为」。
2026-10-11 / 静态数据 ID 统一为 f-mat- / f-ind- / f-org- / tl- 等前缀，引用时直接写原 id / 避免界面层与数据层各自假设一套 id。
2026-10-11 / 静态约束提示词前缀改为 rch- / 避免与用户条目 RC- 在大小写不敏感的匹配中冲突。
2026-10-11 / main 追平：三 docs 分支内容已合入 / 此前 `docs/contract-v2`、`docs/contributing-and-contract-fixup`、`docs/fix-id-prefix` 长期未进 `main`，远程 `main` 一度仅 `ab66919` 脚手架；现 `git log origin/main` 在脚手架之上新增 `2bc1481 Docs/fix id prefix (#3)`，node 核验 principles=33、constraints=rch-001…005，判定文档与静态数据已追平。合入方式为 squash（main 上仅 1 条新提交，无 merge 节点）。
2026-10-11 / 停止使用 Pull Request，改为单分支直推 main / 2 人团队下 PR 的边际价值低于其协调成本（每次改动都要等对方点合并），且交付时间紧张。安全网改为推送前本地闸门（冒烟测试 + 双击验证）与 checkpoint 标签回退。代价是失去第二双眼睛，故禁止强推与历史改写。
2026-10-11 / 禁止强推与历史改写，统一用 git revert 回退 / 单分支直推下 main 是唯一事实来源，改写历史会让双方本地仓库分叉且无法安全回退。revert 生成反向提交，安全且可追溯。
2026-10-11 / validateStep 返回字段统一为 anchors / 契约原写 locators，实现用 anchors。该字段只用于界面定位、不进入持久化状态，故以实现为准修正契约，不升 dataVersion / stateVersion。

2026-10-11 / 用户要求精确创建 frontend 分支，从 origin/main 起步 / 只向该分支推送，不合并 main。
2026-10-11 / Fieldnotes 使用研究工作本布局，原始材料常驻、结论从空白开始 / 用关联与复核支持人工推理，避免自动分析。
2026-10-11 / 双语只翻译 UI，不改用户原文 / 保留作者意思，教材原句另行保留。
2026-10-11 / 在 src/ui 提供可替换预览 runtime 与 preview.html 构建 / PI 的 logic、data、tools、dist 保持其归属，前端可独立评审。
2026-10-11 / 修改原因用卡片历史图标主动记录，不在每次输入时弹窗 / 支持留痕，同时不打断中文输入和小组讨论。

2026-10-11 / 按用户反馈将前端收敛到单步骤工作台 / 原三栏、三视图、底部工具栏造成入口竞争，现主页面只突出填写。
2026-10-11 / 使用深蓝、亮蓝、白色和少量黄绿色 / 提高视觉对比，替换原先过淡的纸色方案。
2026-10-11 / 推理总览、快照、展示和样例退出当前 UI / 后续有需要再扩展；已有状态、运行时 API 和 JSON 数据保留，旧界面可从 Git 复用。
2026-10-11 / 低频内容按需展开 / 主体、原则设置、冲突、自查默认折叠，渲染时保留展开状态和输入法组合。

2026-10-11 / 用户最新授权 frontend 全部进入 main / 遵循最新单分支协作规则，以普通合并保留历史与同学新增内容，不使用强推。
2026-10-11 / 通用工作台与具体资料包分开 / 用户明确要求泛化；十步方法、原则和界面可复用，原案例仍作为独立资料包保留。
2026-10-11 / 新建案例使用独立草稿，JSON 携带资料包 / 防止不同案例文字与依据混在一起；以 UI 层封装扩展，不增删冻结的 v2 分析根字段。
2026-10-11 / 新案例事实与来源由使用者填写 / 程序支持整理和关联，不生成事实或判断；新案例不继承原案例解释性参考。
2026-10-11 / 放大导航并给中部加入蓝灰、淡蓝与暖色层次 / 提高投影可读性，减少纯白面积，保留当前简洁布局。
